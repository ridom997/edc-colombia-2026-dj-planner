DOWNLOAD SAFELY
Use only the project published at github.com/ridom997/edc-colombia-2026-dj-planner. Download the raw DJs_EDC_Colombia_2026.js file, not the GitHub web page.

INSTALL
IPHONE: Install Scriptable from App Store. Import the JS, then run inside Scriptable. If import is unavailable: + → paste ALL the file → save → run.
ANDROID: Install DroidScript: JS and Python IDE by droidscript.org from Google Play. Create a Native JavaScript project. Replace the main JS example with ALL the downloaded file. Save → Run. Reuse the same project.

USE
1. Open schedule → choose a day.
2. Choose my DJs → hour → tap + in priority order. Tap a number to remove it.
3. A chosen DJ continues into later hours. Skip this hour affects only this hour. Resume restores it. New choices start at priority 1.
4. View set times → event, personal or group → List / Timeline. Tap any timeline block for full details. Use − / + to zoom (50–160%); text stays the same size.
5. Export my choices → share the JSON contents → Import final plan → paste the JSON → Validate and import. Confirm to save. Your personal choices are preserved.

SAVE
Choices save automatically. Close and reopen in airplane mode before the event. Export a backup before replacing the script or deleting the host app.

# Publish the new release / Publicar la nueva release

## English

1. Commit and push this project to main.
2. Open https://github.com/ridom997/edc-colombia-2026-dj-planner/releases/new
3. Create tag **json-import**, targeting the updated **main** branch.
4. Title: **DJs EDC Colombia 2026 — JSON Import**.
5. Attach **DJs_EDC_Colombia_2026.js**, select Latest and publish.

## Español

1. Haz commit y push del proyecto actualizado a main.
2. Abre https://github.com/ridom997/edc-colombia-2026-dj-planner/releases/new
3. Crea la etiqueta **json-import**, apuntando a la rama **main** actualizada.
4. Título: **DJs EDC Colombia 2026 — JSON Import**.
5. Adjunta **DJs_EDC_Colombia_2026.js**, marca Latest y publica.

Download / Descarga: https://github.com/ridom997/edc-colombia-2026-dj-planner/releases/download/json-import/DJs_EDC_Colombia_2026.js

The link works only after publishing the release and attaching the file. / El enlace funcionará después de publicar la release y adjuntar el archivo.
